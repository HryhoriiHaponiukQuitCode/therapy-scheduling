## Purpose

Хто з користувачів застосунку бачить список і картки клієнтів: терапевт — лише своїх клієнтів, планувальник і
адміністратор — усіх; хто не увійшов або ще не має ролі, даних клієнтів не бачить.

## ADDED Requirements

### Requirement: Список своїх клієнтів терапевта

WHEN терапевт відкриває список своїх клієнтів, the system SHALL показати картки лише тих клієнтів, у яких із ним є утримання зі статусом «Held» або сеанс зі статусом «Confirmed», з усіма даними анкети, а якщо таких клієнтів немає — лише повідомлення «No clients yet. Clients appear here when a scheduler holds a slot with you.».

#### Scenario: AC-CARD-04 Терапевт бачить лише своїх клієнтів

- **GIVEN** client6 має утримання зі статусом «Held» у therapist1, client7 — сеанс зі статусом «Confirmed» у therapist1, а client9 — утримання зі статусом «Held» у therapist2
- **WHEN** therapist1 відкриває список своїх клієнтів
- **THEN** він бачить картки client6 і client7 з усіма даними анкети (для client7 — з даними опікуна)
- **AND** не бачить client9

#### Scenario: AC-CARD-09 Терапевт без клієнтів

- **GIVEN** therapist2 не має жодного утримання зі статусом «Held» і жодного сеансу зі статусом «Confirmed»
- **WHEN** therapist2 відкриває список своїх клієнтів
- **THEN** він бачить повідомлення «No clients yet. Clients appear here when a scheduler holds a slot with you.»
- **AND** жодної картки

### Requirement: Картка чужого клієнта

IF терапевт відкриває картку клієнта, у якого з ним немає утримання зі статусом «Held» чи сеансу зі статусом «Confirmed», THEN the system SHALL показати повідомлення «You don't have access to this client.», не показувати жодних даних цього клієнта й не змінювати його картку.

#### Scenario: AC-CARD-05 Картка клієнта іншого терапевта

- **GIVEN** client9 — свій клієнт лише для therapist2
- **WHEN** therapist1 відкриває картку client9 за прямим посиланням
- **THEN** therapist1 бачить повідомлення «You don't have access to this client.»
- **AND** жодних даних client9 не показано
- **AND** картка client9 не змінилася

#### Scenario: AC-CARD-08 Клієнт після прострочення утримання

- **GIVEN** утримання client6 у therapist1 має статус «Expired», і інших утримань чи сеансів client6 з therapist1 немає
- **WHEN** therapist1 відкриває список своїх клієнтів, а потім картку client6 за прямим посиланням
- **THEN** client6 у списку немає
- **AND** за посиланням therapist1 бачить повідомлення «You don't have access to this client.» і жодних даних client6

### Requirement: Терапевт не створює картки

IF користувач з роллю `therapist` пробує створити картку клієнта, зокрема з форми нової картки, відкритої за прямим посиланням, THEN the system SHALL не створювати картку, показати повідомлення «Only schedulers and admins can create client cards.» і не змінювати кількість карток клієнтів.

#### Scenario: AC-CARD-06 Терапевт пробує створити картку

- **GIVEN** therapist1 увійшов у застосунок
- **WHEN** він відкриває форму нової картки клієнта за прямим посиланням і пробує створити картку
- **THEN** картку не створено
- **AND** therapist1 бачить повідомлення «Only schedulers and admins can create client cards.»
- **AND** кількість карток клієнтів не змінилася

### Requirement: Користувач без входу

IF користувач, який не увійшов у застосунок, відкриває за прямим посиланням список клієнтів, картку клієнта або список утримань, THEN the system SHALL показати лише сторінку входу, без жодних даних клієнтів чи утримань, і не змінювати жодної картки.

#### Scenario: AC-CARD-07 Пряме посилання без входу

- **GIVEN** користувач не увійшов у застосунок
- **WHEN** він відкриває за прямим посиланням список клієнтів, картку client6 або список утримань
- **THEN** він бачить лише сторінку входу
- **AND** жодних даних клієнтів чи утримань не показано
- **AND** жодна картка не змінилася

### Requirement: Усі картки для планувальника й адміністратора

WHEN планувальник або адміністратор відкриває список клієнтів, the system SHALL показати картки всіх клієнтів, а в картці дитини — дані опікуна.

#### Scenario: AC-CARD-10 Планувальник і адміністратор бачать усі картки

- **GIVEN** існують картки client6, client7 і client9
- **WHEN** scheduler2 або admin1 відкриває список клієнтів
- **THEN** кожен із них бачить усі три картки
- **AND** у картці client7 — дані опікуна

### Requirement: Користувач без ролі

IF користувач, який увійшов, ще не має ролі, THEN the system SHALL показувати йому на будь-якій сторінці застосунку лише повідомлення «Your account has no access yet. Contact an administrator.», без жодних даних клієнтів, і не змінювати жодної картки.

#### Scenario: AC-CARD-11 Користувач без ролі

- **GIVEN** користувач newuser1@example.test увійшов, але не має ролі
- **WHEN** він відкриває застосунок або картку client6 за прямим посиланням
- **THEN** він бачить лише повідомлення «Your account has no access yet. Contact an administrator.»
- **AND** жодних даних клієнтів не показано
- **AND** жодна картка не змінилася
