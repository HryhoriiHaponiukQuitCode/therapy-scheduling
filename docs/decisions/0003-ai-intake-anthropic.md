# 0003. AI-функція зрізу 4: AI SDK і модель Anthropic claude-haiku-5-5

- Статус: прийнято
- Дата: 2026-11-16
- AC: AC-INTAKE-01…09

## Контекст

Зріз 4 (вимога PM #36): чернетка картки клієнта з тексту звернення. Потрібні виклик моделі на сервері, відповідь за
схемою зі станами (`ok / needs_info / refused`), передбачувані збої (немає ключа, 429, таймаут, не за схемою —
AC-INTAKE-08) і офлайн-реплей golden cases у CI. Нові залежності — «Спитай спершу» (`AGENTS.md`).

Набір курсу (`materials/ai-feature`, взято з <https://github.com/koldovsky/2026-quitcode-10-ai-features-hw/tree/main/materials/ai-feature>)
бере безкоштовні моделі OpenRouter (`:free`). Розробник вирішив працювати з власним ключем Anthropic.

## Рішення

- Залежності з точними версіями: `ai` 7.0.162 (як у наборі), `@ai-sdk/anthropic` 4.0.96 (та сама версія
  `@ai-sdk/provider` 4.0.35, що в `ai` 7.0.162), `zod` 4.6.7, `server-only` 0.0.1.
- Модель продукту — `claude-haiku-5-5` (Anthropic), одна, без ланцюжка fallback; недоступна — AC-INTAKE-08.
- Ключ `ANTHROPIC_API_KEY` читає лише `src/lib/ai/anthropic.ts` з `import "server-only"`; у Vercel — Production і
  Preview, локально — `.env.local`; ніколи `NEXT_PUBLIC_` (тест `tests/ai-key.test.ts`).
- `maxRetries` 0, таймаут 20 с; модель без інструментів, у базу не пише.
- `temperature` не передаємо: `claude-haiku-5-5` його не підтримує (AI SDK попереджав і ігнорував параметр).

## Розглянуті варіанти

- **Безкоштовні моделі OpenRouter (`:free`)**, як у наборі курсу: README HW10 вимагає саме їх («лише `:free` у ланцюжку
  моделей»). Не обрано: рішення розробника — власний ключ Anthropic. **Це свідоме відхилення від вимоги домашки:**
  рубрика HW10 не зараховує платну модель у ланцюжку, тож можлива втрата балів у треку B.
- **Anthropic SDK напряму** (`@anthropic-ai/sdk`): не обрано — AI SDK дає `Output.object` зі схемою zod і
  `MockLanguageModelV4` для офлайн-реплею, як у наборі курсу.

## Наслідки

- Кожен запит платний (частки цента на `claude-haiku-5-5`); денного ліміту 50 запитів безкоштовного тарифу немає, тож
  живий eval і приймання PM можуть бути в одну добу.
- Дані в промпті — лише синтетичні (`*@example.test`), як і для безкоштовних моделей.
